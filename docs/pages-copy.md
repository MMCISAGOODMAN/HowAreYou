## 筛选栏选项名称

不要写「工龄区间」。让人凭感觉点。

| 选项 | 说明（仅给实现者，不展示给用户） |
| --- | --- |
| 全部 | 默认 |
| 刚入行 | 入行约 2 年以内 |
| 写了好几年 | 入行 2 年以上 |
| 最近有小成就 | 成就字段非空 |
| 最近有点卡住 | 困惑字段非空 |

搜索框占位符：`搜一个名字，或一句你也有过的话`

---

## 卡片信息优先级

卡片上从高到低，只露出能让人停住的信息；其余进详情页。

1. **一句话介绍**（最大、最先被读到）
2. **当前状态**（第二眼：ta 白天在过什么样的日子）
3. **成就或困惑，二选一露出**（筛「最近有小成就 / 最近有点卡住」时跟筛选对齐；否则取更短且不重复标题的那句）
4. **入行年份**（角落小字即可，如「2018 年入行」）
5. **GitHub ID**（作为署名，可点回 GitHub）

**不要放在卡片上、请放进详情的：**

- 「想对路过的人说」全文
- 「业余在折腾什么」
- 彩蛋题

详情页顺序建议：介绍 → 当前状态 → 业余 → 成就 → 困惑 → 想说的话 → 彩蛋 → 入行时间。

详情页按钮：

- 保存分享图
- 复制金句（优先「想对路过的人说」）
- 看见了（复制一句短话，并打开对应 Issue 点 👀）

卡片与详情均可露出小徽章：「留下了自己」「还在」。

## 空状态

**仓库里还没有人**

还没有人写下自己。  
这很好——说明你来得正好。

按钮：成为第一个

**当前筛选没有结果**

这种心情，暂时还没人写到。  
也许下一条，就是你的。

按钮：看看全部 / 写下我的状态

**搜索没有结果**

没有找到「{query}」。  
人还不多，话却都很具体——换个词，或直接去写一句你自己的。
