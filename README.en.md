# How Are You

**[中文](README.md) | English**

**Real developer status, written on GitHub.**

You finish a bug at midnight, close the editor, and don’t know who to send that sentence to.  
Coworkers are asleep. Friends don’t know CORS. Social feeds are too loud.

So leave it here.

**How Are You** is an open chronicle for ordinary developers. You add a file named after your GitHub ID under
`profiles/`, and write what you’re doing, a small win, or where you’re stuck. People passing by notice: it isn’t only
me.

Any seniority, any stack. You don’t need to “deserve” open source. If you write code, you can be seen.

**Live site:** [https://MMCISAGOODMAN.github.io/HowAreYou/](https://MMCISAGOODMAN.github.io/HowAreYou/)

On the site you can **meet someone at random**, or open the *
*[chronicle](https://MMCISAGOODMAN.github.io/HowAreYou/year)**. Switch the UI between Chinese and English in the
top-right corner; profile text stays in the author’s words.

## How to join

About fifteen minutes. Casual writing is fine.

1. **Open the template:** [TEMPLATE.en.md](TEMPLATE.en.md) (Chinese: [TEMPLATE.md](TEMPLATE.md)).
2. **Create a file:** `profiles/@YourGitHubID.md`.
3. **Send a PR:** details in [CONTRIBUTING.en.md](CONTRIBUTING.en.md).

New to Git? [Open an Issue](https://github.com/MMCISAGOODMAN/HowAreYou/issues/new) and paste your filled template;
maintainers will add the file.

Repo: https://github.com/MMCISAGOODMAN/HowAreYou

---

## Rules

Short, not stern.

- **Be honest.** Not a year-end review or a tech blog. An afternoon of being stuck belongs here.
- **Be kind.** Don’t mock someone else’s status.
- **Not a flex.** This isn’t about who is sharper—it’s about who is willing to be seen.
- **Your file is yours.** Update it with another PR whenever you need.
- **One ID, one file.** Name it `@GitHubID.md`.
