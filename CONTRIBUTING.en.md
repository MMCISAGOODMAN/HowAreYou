# How to leave your status here

If this is your first open-source PR—welcome. These steps assume you’ve never done one. If you get stuck, it’s on us for
not being clear; say so on the PR or Issue.

Two paths. Pick the comfortable one.

```
Want to leave a status
├── Path 1: Open a Pull Request (recommended—a gentle first contribution)
└── Path 2: Open an Issue (maintainers will add the file for you)
```

---

## Path 1: Pull Request

Repo: https://github.com/MMCISAGOODMAN/HowAreYou

### 1. Fork this repo

Open the link above, click **Fork** (top right). Wait a few seconds until you’re on `your-username/HowAreYou`.

### 2. Open the `profiles/` folder

In your fork, go into `profiles/`.

### 3. Create a file

Click **Add file → Create new file**.

Name it:

```
@YourGitHubID.md
```

If your GitHub username is `linus`, the file is `@linus.md`. Keep the `@` and the `.md`. One person, one file—don’t use
someone else’s ID.

### 4. Paste the template, write yourself

Open [TEMPLATE.en.md](TEMPLATE.en.md) (or [TEMPLATE.md](TEMPLATE.md) for Chinese), copy it into the new file, delete the
bracket hints, answer in your own words.

Messy is fine. Spelling, punctuation, leftover examples—none of that fails you.

### 5. Commit the file

Scroll to the bottom:

- Commit message can be: `Add profile @YourGitHubID`
- Click **Commit new file**

### 6. Open a Pull Request

On your fork you’ll often see **Contribute → Open pull request**. Or: **Pull requests → New pull request**. Confirm:

- Left (base): `MMCISAGOODMAN/HowAreYou` on `master`
- Right (head): your fork and the commit you just made

Title can match the commit. Description can be one line: “This is me right now.” Then **Create pull request**.

### 7. Wait—or shout

Maintainers glance at the filename and basics, then merge.  
If GitHub complains about conflicts, grey buttons, or you’re unsure—**comment on the PR**. We’ll sort it together. You
don’t need to learn rebase for this.

After merge, your file lives in `profiles/`. You’ve written yourself into the chronicle.

---

## Path 2: Issue (no Git required)

1. Fill in [TEMPLATE.en.md](TEMPLATE.en.md) anywhere you like.
2. Open a new Issue: https://github.com/MMCISAGOODMAN/HowAreYou/issues/new
3. Title: `[profile] @YourGitHubID`
4. Paste the filled template into the body.
5. Submit.

Maintainers will create `profiles/@YourGitHubID.md`. You still count as a full participant—open source was never only
for people who speak Git.

---

## Updating later

People change. Walk Path 1 again and **edit your own file**—don’t open a second one. Issues work too: “Please swap my
stuck section for…”

---

## A few soft words

- First-time nerves are normal. This repo is built for that.
- There’s no “not good enough.” CORS afternoons and scared mornings both qualify.
- Rules are short, in [README.en.md](README.en.md): honest, kind, not a flex contest.
- You don’t owe anyone a polished bio. You’re answering one question: how are you, lately?

Thanks for being willing to be seen.
